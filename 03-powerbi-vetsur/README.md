# Proyecto 3 (Power BI): ventas y rentabilidad de VetSur

- **Qué mide:** ventas, costos y margen de una red de clínicas veterinarias con seis sucursales.
- **Fuente:** datos del Caso 3 VetSur, entregados en el ramo.
- **Período y frecuencia:** enero 2024 a diciembre 2025, transacciones diarias analizadas por mes.

## Hallazgos
- Ventas totales de $91.606.910 y margen bruto de 37,19%.
- Las ventas crecieron 17,78% en 2025. Vacunas fue la categoría que más creció (+52,90%).
- Anomalía: Talca cayó 54,65% entre mayo y julio de 2025 respecto del mismo período de 2024.
- Antiinflamatorio vende mucho pero deja solo 7,14% de margen.

## Archivos
